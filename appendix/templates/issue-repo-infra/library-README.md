# library

GKE on TPU 与网络方向给客户的成品文档：手册、讲义、技术报告。由 Google 维护。

每份材料一个目录，目录名用英文短横线，里面放正文（HTML / PDF / Markdown）和它用到的图。新材料放进来后在下表加一行。

| 材料 | 目录 | 版本 |
|---|---|---|
| <材料名> | [`<目录>/`](<目录>/)（有在线版的给链接） | <版本或日期> |
| <带 demo 的手册> | [`<目录>/`](<目录>/README.md)；demo 在 [`recipes/<目录>/`](../recipes/<目录>/README.md) | <版本或日期> |

网页版材料下载仓库后用浏览器打开 `<目录>/index.html` 即可离线阅读。
